## 快速開始

### 第一次使用

1. **找到 Bot**
   - 在 Telegram 搜尋你的 Bot 名稱
   - 或使用 Bot 的 username（例如：@YourParkingBot）

2. **開始對話**
   ```
   /start
   ```
   你會看到歡迎訊息和功能介紹

3. **初始配置**
   ```
   /setup
   ```
   按照提示完成以下設定：
   - 輸入 TDX API 金鑰
   - 輸入 Supabase 連線資訊
   - 確認配置成功

4. **開始使用**
   - 配置完成後，就可以使用所有功能了！

## 功能詳解

### 1. 停車位搜尋 (`/parking`)

#### 使用步驟

1. **啟動搜尋**
   ```
   /parking
   ```

2. **提供位置**
   
   方式 A：分享 Telegram 位置
   - 點擊「📍 分享當前位置」按鈕
   - 允許 Telegram 存取位置
   
   方式 B：提供 Google Maps 連結
   - 開啟 Google Maps
   - 長按地圖上的位置
   - 點擊「分享」→ 複製連結
   - 貼到 Bot 對話中

3. **選擇搜尋半徑**
   - 500 公尺：步行範圍
   - 1 公里：短距離
   - 2 公里：較大範圍

4. **查看結果**
   
   Bot 會顯示：
   - 停車場名稱
   - 距離（公尺）
   - 剩餘車位 / 總車位
   - 收費資訊
   - 導航連結

#### 結果範例

```
🅿️ 找到 5 個停車場

📍 台北市政府地下停車場
距離：350 公尺
剩餘車位：45 / 200
收費：每小時 30 元
[📍 導航](https://maps.google.com/...)

📍 市民大道路邊停車
距離：420 公尺
剩餘車位：8 / 20
收費：每小時 40 元
[📍 導航](https://maps.google.com/...)
```

#### 使用技巧

- 🎯 **精確搜尋**：使用 Google Maps 連結可以指定確切位置
- 🚶 **步行距離**：選擇 500m 半徑最適合步行
- 🚗 **開車範圍**：選擇 1-2km 半徑適合開車前往
- 🔄 **重新搜尋**：如果結果不滿意，可以點擊「重新搜尋」

### 2. 路況查詢 (`/traffic`)

#### 使用步驟

1. **啟動查詢**
   ```
   /traffic
   ```

2. **選擇搜尋範圍**
   - 250 公尺：附近路段
   - 500 公尺：周邊區域
   - 1 公里：較大範圍

3. **提供位置**
   
   方式 A：分享 Telegram 位置
   - 點擊「📍 分享當前位置」按鈕
   - 允許 Telegram 存取位置
   
   方式 B：提供 Google Maps 連結
   - 開啟 Google Maps
   - 長按地圖上的位置
   - 點擊「分享」→ 複製連結
   - 貼到 Bot 對話中

4. **查看結果**
   
   Bot 會顯示：
   - 附近路段名稱
   - 距離
   - 路況狀態（順暢/車多/塞車）
   - 車速資訊
   - 交通事故/施工資訊

#### 結果範例

```
🚦 附近路況 (5則重要資訊)

🚨 基隆路一段 (307m)
   車輛事故

🔴 松高路 (349m)
   塞車 22km/h

🔴 環東大道 (374 - 734m)
   塞車 27~55km/h

🚧 信義快速道路 (898m)
   道路施工

🟡 市民大道 (1.2km)
   車多 45km/h
```

#### 使用技巧

- 🕐 **出發前查詢**：建議出發前 5-10 分鐘查詢
- 🔄 **即時更新**：路況資訊每 5 分鐘更新
- 🚨 **注意事故**：紅色標示的事故影響較大，建議改道
- 📍 **精確位置**：使用 Google Maps 連結可以指定確切位置

### 3. 配置管理

#### 查看配置 (`/config`)

顯示當前配置狀態：
- TDX API 金鑰狀態
- Backend 類型
- 配置時間

```
📋 當前配置

✅ TDX API 金鑰：已設定
🔧 Backend 類型：supabase
📅 配置時間：2024-01-15 10:30:25
```

#### 重置配置 (`/reset`)

⚠️ **警告**：重置會清除所有資料，包括：
- API 金鑰
- Backend 設定

使用步驟：
1. 輸入 `/reset`
2. 確認重置
3. 重新執行 `/setup` 配置

## 使用技巧

### 1. 位置輸入技巧

#### 使用 Telegram 位置
- ✅ 優點：快速、準確
- ❌ 缺點：需要開啟位置權限

#### 使用 Google Maps 連結
- ✅ 優點：可以指定任意位置
- ✅ 優點：不需要位置權限
- 💡 技巧：可以搜尋地址後分享

### 2. 搜尋半徑選擇

| 半徑 | 適用情境 | 結果數量 |
|------|----------|----------|
| 500m | 步行、附近停車 | 較少但精準 |
| 1km | 短距離開車 | 適中 |
| 2km | 較大範圍搜尋 | 較多選擇 |

### 3. 節省 API 用量

- 🔄 **使用快取**：5 分鐘內重複查詢會使用快取
- 📍 **精確位置**：提供精確位置可減少重複搜尋
- ⏰ **合理頻率**：避免短時間內重複查詢

### 4. 最佳使用時機

#### 停車位搜尋
- 🕐 **到達前 5-10 分鐘**：確保資訊最新
- 🚗 **開車途中**：可以請副駕駛協助查詢

#### 車流查詢
- 🕐 **出發前 5-10 分鐘**：掌握即時路況
- 🔄 **途中更新**：長途旅程可中途再查詢
- 📍 **多點查詢**：可以查詢沿途多個地點的路況

## 常見問題

### Q1: 找不到停車場資訊？

**可能原因**：
- 該區域沒有提供即時資訊
- TDX API 暫時無法使用
- 搜尋半徑太小

**解決方法**：
- 擴大搜尋半徑
- 稍後再試
- 更換搜尋位置

### Q2: 路況資訊不準確？

**說明**：
- 路況資訊來自 TDX API，更新頻率約 5 分鐘
- 實際路況可能有變化
- 建議作為參考，不要完全依賴

### Q3: API 金鑰無效？

**解決方法**：
1. 確認金鑰複製完整（很長的字串）
2. 檢查 TDX 平台金鑰狀態
3. 重新申請金鑰
4. 使用 `/reset` 重新配置

### Q4: Bot 回應很慢？

**可能原因**：
- TDX API 回應慢
- 網路連線問題
- Bot 伺服器負載高

**解決方法**：
- 稍等片刻（最多 10 秒）
- 檢查網路連線
- 如果持續緩慢，請回報問題

### Q5: 如何更新配置？

**方法 1**：重置後重新配置
```
/reset
/setup
```

**方法 2**：直接執行 setup（會覆蓋舊配置）
```
/setup
```

### Q6: 可以同時查詢多個位置嗎？

**答**：目前不支援。每次只能查詢一個位置，但可以快速切換查詢不同位置。

### Q7: 資料會保存多久？

**保存期限**：
- 使用者配置：永久（除非重置）
- 快取資料：5 分鐘

## 隱私與安全

### 資料收集

Bot 只收集必要資訊：
- Telegram User ID（用於識別使用者）
- TDX API 金鑰（加密儲存）
- 查詢記錄（用於試用模式限制）

### 資料安全

- 🔐 API 金鑰使用 AES-256 加密
- 🔒 資料儲存在 Supabase（符合 GDPR）
- 🚫 不會分享給第三方
- 🗑️ 可隨時使用 `/reset` 清除所有資料

### 位置隱私

- 📍 位置資訊不會被儲存
- 🔍 只用於即時查詢
- 🚫 不會追蹤使用者位置
